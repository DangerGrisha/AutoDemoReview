# What tools/convert_sounds.ps1 takes from CS2, by CS2's own sound event names. Each event
# says which files it plays and at what volume and pitch, so none of that is guessed here.
#
#   <key> <event>
#
# The key is what web/static/replay3d/sfx.js asks for. shot:<tag> and far:<tag> go by the
# weapon tags of rust/extract/src/weapons.rs; a gun with no far: line in CS2 keeps its
# near sound at any distance.
#
# No event here may loop: constant beds (fire, smoke, room tone) were tried and hated.
# BaseSmokeEffect.Sound is 14 s of hiss, so the page plays only its start.
